# BitChat-Android-Analysis
Static security analysis of BitChat Android v1.7, a decentralized Bluetooth mesh messaging application. The analysis applies a three-pillar evaluation framework — trust establishment, conversation security, and transport security — examining both design-level and implementation-level failures. 18 findings were identified across the three pillars, ranging from critical architectural flaws in the identity and signature mechanisms to implementation errors that defeat the confidentiality guarantees of the Noise protocol. The status of each finding against subsequent releases up to v2.0.3 is tracked in the summary table. Analysis was conducted through static source code review using Android Studio, JADX, and MobSF. Dynamic analysis was not completed.
